# RyoURL-frontend
RyoURL's frontend page.

## Development

This is a static single-page frontend built with Tocas UI.

```bash
python3 -m http.server 5174 --bind 0.0.0.0
```

Open `http://127.0.0.1:5174` locally, or `http://<host>:5174` from the network.

The default API endpoint follows the current page hostname on port `8003`, and it can be changed in the top bar.
